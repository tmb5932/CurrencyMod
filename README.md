# Currency Mod
Currency Mod is a Minecraft Mod for version 1.20.1, that was originally planned to add more trades and creating more opportunities and paths to getting valuables, but has since expanded past the original scope.

## Features
- **Custom Villager Trades**
- **Custom Items**
  - Dye Bottles
  - Dollar Notes
  - Ore Detector
  - Rollable Dice
- **Custom Storage Items**
  - Wallet
- **Custom Interactive Blocks**
  - Ink Juicer
  - Enhancement Station
  - Industrial Printer
  - Stamping Machine
- **Custom Menus**
- **Custom Block Textures**
- **Custom Crafting Recipes**
- **Custom Ores**
- More trades, items, and blocks in the works!
